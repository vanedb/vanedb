# VaneDB 0.2.0 RC3

Third release candidate for integration testing, not final 0.2.0 acceptance.
Rust, npm and native C assets use `0.2.0-rc.3`; Python normalizes that version
to `0.2.0rc3`. Publication status is recorded on the GitHub release and in
the registry; preparing these notes does not establish published availability.

## Install and test

Use a fresh environment and pin the candidate explicitly:

```sh
cargo add vanedb@0.2.0-rc.3
python -m pip install vanedb==0.2.0rc3
npm install @vanedb/wasm@0.2.0-rc.3
```

Python requires 3.11 or newer. Wheels cover Python 3.11–3.14 on Linux
x86-64/ARM64 (glibc and musl), macOS x86-64/ARM64 and Windows x64; the source
distribution is also included. The npm package serves Node and browser
consumers and is published under `next`, leaving `latest` unchanged.

Native C archives and their signed SBOMs are attached to the
`vanedb-crate-v0.2.0-rc.3` GitHub prerelease for Linux x86-64/ARM64, macOS
x86-64/ARM64 and Windows x64. Verify the complete asset set using its included
`CAPI-VERIFYING.md`, which records the tag identity and exact source commit.
There are no new iOS/Android binary packages or C++ Python publication in
this release.

## Changes since RC2

- **Graph construction no longer strands stored vectors (#299).** RC2 made
  stranded vectors retrievable only by a beam as wide as the whole index.
  The graph itself is now kept connected: layer 0 carries a spanning tree
  that pruning never cuts, within the existing degree cap and with the file
  format unchanged. On DOT and tightly clustered cosine data earlier
  candidates could leave most of a large index unreachable from its entry
  point. Graphs built by RC3 differ from those built by RC2 for the same
  input and seed.
- **WebAssembly: asynchronous predicates are refused.** A search `predicate`
  that returns a thenable or a generator throws `TypeError` instead of
  matching every stored id, including a Promise from another JavaScript
  realm and under a Content Security Policy that forbids code generation
  from strings.

See [CHANGELOG.md](../../CHANGELOG.md) for the complete list.

## What to test in particular

- `ApproxIndex` recall on your own data against `FlatIndex`, especially with
  `Metric::Dot` and with clustered cosine embeddings. Compare with RC2 if you
  have numbers.
- An index saved by 0.1.1, RC1 or RC2: it loads with the topology it was
  saved with. `compact()` rebuilds it with the fix.
- Adding vectors to a loaded index. The first insert after a load derives
  the spanning tree over the whole graph (about 0.03 s at 300,000 × 128 on an
  M4 Pro, linear in size).

## C ABI migration

Unchanged from RC2. Recompile consumers against the candidate header. Store,
index and disk handles are `uint64_t`, not pointers; use
`VANEDB_RS_NULL_HANDLE` (0), `PRIu64`, and `c_uint64` in Python ctypes
declarations. Check `VANEDB_RS_ABI_VERSION` against `vanedb_rs_abi_version()`
before other calls. The guard protects only binaries that call it: a 0.1.1
binary started against this library is not detected. See the
[C ABI guide](../../vanedb-capi/README.md).

Keep mapped disk files immutable until the handle has been freed and all
in-flight calls have returned.

## Known limitations and final-release gates

- Reachable is not the same as found. A bounded approximate search can still
  miss a stored vector its beam never gets near; only a search whose
  effective beam reaches every stored slot is exact. See
  [docs/LIMITS.md](../LIMITS.md).
- At low filter selectivity the default beam and cap may return fewer than
  `k` results; raise `ef_search` or `max_ef_search` (#304).
- Dedicated-hardware performance acceptance on Apple Silicon and the Android
  ARM64 comparison remain open, as does final independent release sign-off.
  The Linux x86-64 AVX2 comparison tables are deferred past 0.2.0
  (RFC 0003, amendment of 2026-11-10). This RC makes no performance claim.
- Metal is experimental and accelerates no index; CUDA is not implemented.
  Mobile runtime evidence is limited to simulators/emulators.

Report the RC package version, OS/architecture, installation method and a
minimal reproducer with any issue.
