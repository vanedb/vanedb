## OrbStack and the Linux requirement

OrbStack can run Linux here, but cannot fill this release's native Linux x86-64
AVX2 performance slot on the M4 Pro. Its two existing machines are ARM64;
OrbStack documents that x86 programs on Apple Silicon use
[Rosetta emulation](https://docs.orbstack.dev/architecture). An amd64 machine
name or reported instruction support would not make translated execution native.

[Machine CPU and memory limits](https://docs.orbstack.dev/machines/#resource-limits)
can bound resource use, but do not change the physical ISA or establish exclusive
CPU ownership. No VM was created or changed. Qualifying Linux measurements still
need an x86-64 AVX2 host; a VM on that host additionally needs documented resource
isolation. ARM Linux or translated x86 tests may provide functional diagnostics,
but cannot replace this performance hardware class.
