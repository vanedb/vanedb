## Capacity dependency requiring resolution

Issue #210 remains in this milestone and asks for measured resident, mapped,
and binary-plus-rescoring modes. The accepted RFC 0008 amendment schedules
the mapped experiment after RFC 0005 quantization, which the roadmap assigns
to later releases. The analysis in `docs/research/capacity.md` explicitly
does not claim those measurements. Gather currently executable measurements
and record a maintainer decision for the dependency conflict; neither issue
closure nor this checklist waives the outstanding acceptance criteria.
