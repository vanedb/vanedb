## Capacity dependency requiring resolution

Issue #210 remains in this milestone and asks for measured resident, mapped,
and binary-plus-rescoring modes. The accepted RFC 0008 amendment schedules
the mapped experiment after RFC 0005 quantization, which the roadmap assigns
to later releases. The analysis in `docs/research/capacity.md` explicitly
does not claim those measurements. Gather currently executable measurements
and record a maintainer decision for the dependency conflict; neither issue
closure nor this checklist waives the outstanding acceptance criteria.

## Final candidate evidence

Record source SHA, artifact checksums, commands, toolchains and run URLs.

RFC criterion, not merely a count of passing tests.

- All `AGENTS.md` local checks, complete platform CI, C++ reference and shared
  VNDB v1/v2 conformance, legacy readers and corruption checks.

  browser persistence/reload and Node restart, extracted shared/static C
  consumers, ABI/export checks and signed-asset verification.

  is actually recorded. Experimental Metal claims remain within the platform
  policy. No CUDA support claim.

  honest measurement limits; CI timings are not release performance proof.

  product-design and UX verdicts, with findings resolved on the current head.
  Merge only with unanimous agreement and green required CI; refresh branches
  whenever protected main changes.

  `publish-rust.yml` (`publish_testpypi=false`), `publish-wasm.yml`, and the C
  release workflow. Publication jobs must skip on dispatch.
