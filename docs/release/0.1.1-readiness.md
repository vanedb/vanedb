reports no longer attach fixed historical statistics to unrelated workloads.
Version declarations and active release documentation agree. These fixes
change neither the search algorithms nor the persistence formats.

## Platform and compatibility scope

Runtime coverage includes Linux x86-64/ARM64, macOS Intel/ARM64 and Windows
x64. Python wheels additionally cover musl Linux. C archives record glibc
requirements and macOS deployment targets; those are binary requirements,
not proof of runtime behavior on the oldest compatible OS.

Mobile acceptance is simulator/emulator based: iOS ARM64, Android x86-64,
and a fresh Android ARM64 / 16 KiB run of this candidate's CI-built binary.
The ARM64 result supersedes the historical-only runtime evidence. Device
builds pass, but physical-device acceptance and oldest-OS runtime acceptance
remain follow-ups. No physical iPhone/Android test is claimed.

Metal is an explicit Rust compute API; it does not automatically accelerate
indexes. CUDA remains a required [post-release follow-up](../ROADMAP.md).
Earlier dedicated-hardware performance evidence applies only to unchanged
implementations; CI timings are not performance evidence. The release delta
keeps third-party dependency versions unchanged.

VNDB v1 disk and VNDB v2 graph formats retain cross-engine conformance and
legacy readers. During 0.x, minor releases may change APIs/formats; existing
format identifiers are never reinterpreted. See the [release notes](0.1.1-notes.md).
