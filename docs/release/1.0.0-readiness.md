# 1.0.0 release readiness

Status: **not ready to tag**. This record tracks evidence and remaining work;
it does not change the release scope or declare support from build checks alone.

## Release scope

Ship the Rust engine, Python package, C ABI and WebAssembly bindings with a
stable public contract, compact maintainable code, runnable user documentation,
and functional verification on every advertised platform. C++ remains frozen
reference code; keep its defect tests and cross-engine fixtures working.

The legacy fixture work then exposed a C++ loader defect: a persisted negative

and NaN stored values. Local verification passes all 88 C++ test cases, the
Rust workspace suite with `disk,gpu-metal`, workspace clippy, and benchmark

standard-library stream layouts rather than claiming those are universal.

the rendered `DiskIndex` and `disk` module pages show the required feature badge.
The conformance guide now distinguishes stored slots from live IDs and documents
the Rust/C++ deletion difference that the shared identity fixtures already use.

[CI at `e3e6197`](https://github.com/vanedb/vanedb/actions/runs/34063395186)
completed successfully before the VNDB graph change.

The VNDB v2 graph implementation now streams fixed-width little-endian writes
and validates nodes, identities, edges and continuation metadata. Thirteen
independent fixtures cover every metric and RNG encoding, empty/all-deleted
graphs, a deleted entry point, and ID reuse. Both engines reproduce these bytes
exactly; engine-written files cross both ways, remain byte-identical before
mutation, and accept further insertion. C++ handles loaded tombstones internally
without a public deletion API. Legacy Rust v1/v2 and C++ v1/v2/v3 readers remain.

Local graph-change verification passes the Rust workspace suite with `disk`,
workspace and benchmark clippy, all 91 C++ test cases, and the benchmark suite
(26 unit tests, two disk cross-load tests, one graph test covering six
source/metric combinations and mutations in both engines). Both graph readers
reject all truncated prefixes of the small fixture, malformed header/node/edge
fields, trailing bytes and invalid continuation encodings. Exact graph bytes
are required; query comparisons allow the existing floating-point tolerance
for nearly tied SIMD distances. Dedicated performance checks and platform CI
for this new implementation are still required.
