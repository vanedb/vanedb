## Scope and compatibility

Ship the Rust engine and its Python, C and WebAssembly bindings, with runnable
user guides and verification of the advertised platform matrix. Keep the C++
reference and its cross-engine tests working. This candidate does not switch
the production engine during the ongoing language-strategy discussion.

The 0.x API and persistence formats may evolve in minor releases. Existing
format, kind and continuation identifiers must not be reinterpreted; new
encodings require new identifiers while retaining readers for existing files.
Older readers need not accept future formats. Both engines currently preserve
VNDB v1 disk and VNDB v2 graph files across load/save, including graph tombstones.
Future insertions may produce different topology. Legacy-reader and corruption
checks remain required; the version change is not permission to discard them.

Optional Metal compute is a Rust API for explicitly uploaded vectors, not
transparent acceleration of the indexes. CUDA is a required, high-priority
[follow-up after the initial release](../ROADMAP.md), with no assigned version
or date. Mobile acceptance uses simulators/emulators; physical-device acceptance
remains a follow-up. Neither CUDA nor physical-device success is claimed here.
