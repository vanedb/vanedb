### Hardware scope carried forward

The current CI ran iOS ARM64 simulator acceptance and Android x86-64 emulator
acceptance, alongside device/ARM64 builds. Its Android ARM64 bundle identifies
CI merge `3074728`, whose parents are main `69a994a` and candidate `d1c32b9`
and whose file tree is identical to the candidate. Both ELF files pass four
LOAD-segment checks for 16 KiB alignment.

The earlier Android 15/16 KiB ARM64 runtime is carried forward only for page-size
compatibility: the mmap path, linker alignment, dependency lockfile, ELF guard
and acceptance test remain unchanged. C ABI and disk-validation behavior did
change and is covered by current platform tests. This is not a fresh ARM64
emulator run or physical-device acceptance. CPU distance and Metal production
implementations are unchanged apart from comments; existing scoped performance
evidence remains applicable to those kernels, and Metal correctness was rerun
on local hardware. No result is extrapolated to CUDA or the oldest compatible OS.
