Seven additional preflight samples exceeded the screen; the controller waited
for a new quiet streak each time. Flagged processes included simulator
`pairedsyncd`/`xpcproxy_sim`, `airportd`, `launchd`, `WeatherWidget`, `contactsd`
and `mediaanalysisd`. A pre-existing iPhone 17 Pro / iOS 26.5 simulator was

Other independent host activity would still need rechecking after that change.

Snapshots cover setup, warmup and measurement; they cannot identify the exact
timed interval affected or prove that each flag materially changed a result.
Conversely, the record does not establish that those flags were harmless. This
is host-quality failure, not automatic evidence of engine slowdown. No clean
individual runs were selected to manufacture a passing comparison.
