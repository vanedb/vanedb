## Independent review and focused wasm correction

Review of PR #356 found that a rejected native Promise from another JavaScript
realm fails the binding's realm-local `instanceof Promise` check. Search throws
its synchronous TypeError, but the rejection remains unhandled: Node can exit
after the caller catches the search error. Both FlatIndex and ApproxIndex
reproduced this against the exact original npm tarball
(`eb0598cd26e7faf6829baa3e175174f8f999c1dc2aeb30ca502059b7e702871d`).
Same-realm controls exited zero; foreign-realm cases exited one under strict
unhandled-rejection handling and disabled string code generation.

[PR #359](https://github.com/vanedb/vanedb/pull/359), stacked on #356, contains
the focused correction at `6e4fc2d88f2f248cb06becb24bcc0ef228323d22`.
The native `Promise.prototype.then.call` brand check accepts Promises across
realms and rejects other thenables without invoking their custom `then`.
One reusable static settlement callback avoids dynamic compilation and abandoned
per-thenable Rust closures. The committed regression includes foreign resolved
and rejected Promises and explicit zero-call controls for plain, callable and
fake-Promise thenables, for both index types.

The new installed-package regression failed against the original artifact and
passed after rebuilding the fix. All 31 wasm Node tests, installed ESM/CommonJS
consumers, persistence crash checkpoints, wasm-target all-target Clippy with
`-D warnings`, and formatting/whitespace checks passed. Independent fixed-package
checks also verified delayed rejection after index disposal and preservation of
original getter errors. Review's counter-based negative-control improvement was
applied and the installed test rerun successfully. This is technical review,
not maintainer approval or the final required multi-role release sign-off.

Local tools: Rust/cargo 1.94.1, wasm-pack 0.14.0, Node 26.13.0, npm 11.20.0,
Python 3.13.5. An initial standalone Clippy invocation selected a different
compiler from PATH and failed because that toolchain lacked the wasm target;
the recorded successful rerun pins the same compiler as the build and tests.

The [fixed-source npm rehearsal](https://github.com/vanedb/vanedb/actions/runs/41604609578)
passed with publication skipped. Its downloaded artifact ZIP and package
checksum were verified, and the committed installed regression passed against
those remotely built bytes. [Full component CI](https://github.com/vanedb/vanedb/actions/runs/41604725593)
was explicitly dispatched because automatic PR CI selects only PRs targeting
main, while #359 is stacked on #356. **All 52 jobs succeeded**, including the
Required CI Gate, core/platform/mobile checks, C++ reference and cross-engine
integration, and wasm/packaged browser acceptance in Chrome, Firefox and WebKit.
Hosted benchmark smoke outputs are diagnostic only, not performance acceptance.
