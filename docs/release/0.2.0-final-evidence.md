## Mac measurements and unresolved interpretation

The reserved Mac full campaign completed on 2026-09-27: baseline `51cb2d871538985aad933a13ebe50c13a0031dfa` versus S, Rust 1.94.1, all 28 Criterion rows in each of six A-B-A-B-A-B passes, followed by four-round canonical cosine/L2 competitor runs using the pinned 100k×768 fixture and1,000 queries. Both competitor JSONs pass the unchanged S render-policy gates and contain the complete expected engine sets. Peer limitations and recall differences remain in the tables.

Ratios of candidate median Rust to median C++ point estimates are **store_add 0.776196×** and **disk_build 1.072842×**, both numerically below 1.1×. However, Rust index_search rose **3.5216%** while the invariant C++ control rose **2.9400%**. Rust's within-arm interpass spread was 0.5759%; repository guidance also identifies an approximate 3% local floor. The raw search increase therefore remains unresolved. C++ normalization is a diagnostic, not a replacement acceptance rule.

The host was reserved and sampled on AC, but process records show substantial system background activity; no recorded thermal warning does not prove uncontended timing. Subsequent focused diagnostics also carry load caveats. A fixed-graph native/C-API probe recorded **native +5.0044%** and **C API +4.4475%**. Added per-call handle-check cost is not supported as the sole explanation; its negative aggregated path differential is not negative mutex cost. A separate confirmation completed only its A arm before the next quiet-host preflight failed and was stopped; it is excluded from the complete ABBA result.

Quick checks found identical baseline/candidate serialized graph bytes and exact query outputs; standalone finite validation measured 7.700ns versus 36.415ns for the scalar reference; object sizes changed by 16 bytes. These narrow hypotheses without proving inlined-search timing or an allocator/layout cause. No functional defect or justified speculative fix was found. **The roughly 5% native diagnostic observation remains disclosed; Mac performance is not signed off.**
