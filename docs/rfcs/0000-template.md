# RFC NNNN: Title

- Status: draft
- Milestone: none
- Tracking issue: none
- Supersedes / superseded by: none

## Problem

What is wrong or missing, for whom, with evidence (an issue, a measurement, a
competitor's behaviour, a user report).

## Decision

One paragraph. What changes and what does not.

## Design

Enough detail that a second person could implement it without asking: types,
signatures, file-format fields, binding surfaces, error behaviour, defaults.

## Alternatives rejected

Each with the reason it loses.

## Compatibility and migration

What an existing caller, file, or binding user has to do. Which invariants in
`AGENTS.md` this touches and how they are preserved.

## Acceptance criteria

A checklist a reviewer can tick. Include the evidence each item needs (which
test, which platform, which recorded run).

## Evidence required before the claim

Hardware, toolchains, recorded runs. Simulator results are not device results;
CI timings are not benchmarks.

## Out of scope

What this RFC deliberately does not do, and where that work belongs.
